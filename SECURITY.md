# Security policy

This repo is the source of [davidkwartler.com](https://www.davidkwartler.com),
a static personal site.

## Reporting a vulnerability

Email [david@davidkwartler.com](mailto:david@davidkwartler.com), the same
contact as [`/.well-known/security.txt`](https://www.davidkwartler.com/.well-known/security.txt).
Please don't open a public issue for a security report.

Only the current `main` branch, as deployed, is supported.
