# davidkwartler.com

Personal portfolio site for David Kwartler: a single-page scroll narrative built to demonstrate craft. The site itself is the proof of "PM who builds."

**Live:** [www.davidkwartler.com](https://www.davidkwartler.com)

## Design direction

- **Base look:** Linear.app-style monochrome. Black and white, minimalist, glow used as hierarchy rather than color splash.
- **Motion quality:** rauno.me-style restraint. Physically plausible micro-interactions; every interactive element acknowledges hover, press, and focus.
- **Personality:** applied sparingly onto the monochrome base through microcopy and small accent moments, not personal-data features.
- **One scroll-scrubbed "Apple moment":** the hero headshot shrinks and travels into the sticky nav as you scroll, landing as the small round avatar.

## Page structure

A single route (`/`) with five sections, plus one hidden page:

1. **Hero** (`sections/Hero.tsx`): full-viewport intro with name, tagline, the scroll-scrubbed headshot, and an animated galaxy background (`GalaxyBackground.tsx`).
2. **What I do** (`sections/WhatIDo.tsx`): role and focus areas.
3. **Career** (`sections/Career.tsx`): horizontal timeline with click/keyboard phase switching, an elevated detail card, and a flowing binary progress stream ("DK MCP" in ASCII).
4. **Human** (`sections/Human.tsx`): three-photo personal section.
5. **Contact** (`sections/Contact.tsx`): contact links over the galaxy.

### /travel easter egg

Reached only by clicking the Travel photo caption in the Human section. Kept off the SEO surface: noindex, no sitemap entry, no nav link.

An orthographic globe rendered on canvas (`TravelMap.tsx`): continents drawn as electric-blue 0/1 glyphs (Fibonacci point field sampled against an equirectangular land mask, `data/land-mask.ts`, generated by `scripts/gen-landmask.mjs`), orange triangle pins for visited cities that hide on the back hemisphere, and a blue home pin for Austin. The globe idles with a very slow wobble constrained to the Atlantic face, supports grab-and-drag within that envelope, and freezes with a hover zoom when you hover or tap a pin to open its field-notes card. City data lives in `data/travel.ts`: each city has a region, coordinates, optional `featured` and `home` flags, and a list of highlights. A background star field (`StarField.tsx`) fills the space around the globe, rejection-sampled outside its footprint.

## Tech stack

- **Next.js 16** (App Router) with **static export** (`output: "export"`), so there is no server runtime; the build emits plain HTML/JS to `out/`
- **TypeScript** throughout
- **Tailwind CSS 4**
- **Motion** (Framer Motion) for scroll and reveal animation
- **Canvas 2D** (no WebGL) for the galaxy, star field, and travel globe
- **Vercel** for hosting, with `@vercel/analytics`

## Repo layout

```
src/
  app/            Routes: layout, home page, /travel, 404, robots, sitemap
  components/     Shared components (nav, footer, canvases, cards)
    sections/     The five home-page sections in scroll order
  data/           All site content lives here, separated from presentation:
                  content.ts (copy), resume.ts (career), travel.ts (cities),
                  land-mask.ts (generated continent bitmap)
  lib/            Hooks and shared config: use-canvas-loop.ts (rAF loop with
                  IntersectionObserver + reduced-motion + pause handling),
                  galaxy-pause.ts (global motion pause store), globe-config.ts,
                  motion.ts (shared easing), use-active-section.ts
public/           Images, favicons, OG image
scripts/          gen-landmask.mjs regenerates src/data/land-mask.ts
```

## Conventions

- **Content vs. presentation:** all copy and data live in `src/data/`; components render it. Editing site text should never require touching a component.
- **Motion respect:** every canvas animation runs through `use-canvas-loop.ts`, which pauses offscreen, honors `prefers-reduced-motion`, and obeys the site-wide pause button (`PauseMotionButton.tsx`).
- **Accessibility:** decorative canvases are aria-hidden with `sr-only` equivalents (the travel globe's city list, for example); interactive elements are keyboard-reachable with visible focus rings.
- **Style:** colons instead of em dashes, everywhere (copy and code comments).
- **Security headers** (CSP and friends) and legacy-URL redirects are configured in `vercel.json`.

## Development

```bash
npm run lint
```

## Workflow

Planning lives in the repo, not GitHub issues: `BACKLOG.md` is the groomed backlog and shipping log, and `REDESIGN.md` is the original single-page redesign handoff doc. Work batches on a feature branch and merges to main only when explicitly shipped; main deploys to production via Vercel.
